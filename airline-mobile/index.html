2. Production-Grade Requirements & Gherkin AC

📱 Feature 1: Offline Apple/Google Wallet Sync & Gate Updates

▼

User Story: As a checked-in passenger, I want to add my boarding pass to Apple Wallet with 1 tap, so that I can access my pass at security terminals without internet.

Scenario 1: Successful Pass Generation & Apple Wallet Hand-off (iOS)
  Given the passenger has successfully completed check-in for flight 1A-450
  And the device operating system is iOS
  When the passenger taps the "Add to Apple Wallet" button
  Then the app generates a valid .pkpass binary payload
  And opens native Apple Wallet pass sheet displaying Aztec barcode and gate details.

🔄 Feature 2: Self-Service Flight Change Engine (MMB)

▼

User Story: As a passenger with a confirmed PNR, I want to search alternative flights and view fare differences in Manage My Booking, so that I can modify travel dates instantly.

Scenario 1: Voluntary Flight Modification with Price Difference
  Given the passenger retrieves a valid PNR eligible for modification
  When the passenger selects a new departure date and picks flight 1A-890
  Then the app queries the pricing engine: Total Due = (New Fare - Old Fare) + Change Fee
  And enables the 3DS payment authorization flow.
