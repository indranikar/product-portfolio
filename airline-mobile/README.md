## 📌 Project Overview

This repository contains an end-to-end **B2B2C Mobile Product Case Study & Interactive PRD Specification** auditing the enterprise airline mobile passenger experience—from booking search to day-of-travel gate operations.

It is designed to demonstrate:
- **Requirements Engineering:** INVEST User Stories + testable **Gherkin Acceptance Criteria (`Given-When-Then`)**.
- **System Architecture:** 4-Layer Mobile Architecture (Client Shell $\leftrightarrow$ Middleware Payload Aggregation $\leftrightarrow$ Airline PSS/DCS Backend).
- **Agile Prioritization:** **RICE Framework** Scoring ($Reach \times Impact \times Confidence / Effort$) and **MoSCoW Scope Allocations**.
- **Mobile Release & QA:** pCloudy physical device testing matrix, **7-Day Phased Rollout Schedule** (1% $\rightarrow$ 100%), and **Remote Feature Flag Kill-Switches**.
- **Observability & ROI Math:** Application stability telemetry (Firebase Crash-Free Rate $\ge 99.5\%$), APM latency tracking (Datadog), and mathematical ROI calculations.
